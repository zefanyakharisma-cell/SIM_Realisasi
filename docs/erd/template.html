Views & rules held by the schema

    %%VIEWS%%
  • One agreement per kegiatan: unique index one_agreement_per_activity on activity_documents (R-03).
  • One current IA, IR and mobility PDF: partial unique index one_current_ia_ir on activity_files.
  • One approved, one draft, one pending participant version per kegiatan: partial unique indexes on participant_set_versions (R-21).
  • Conflict pairs are ordered and decided consistently: activity_a < activity_b; kept_activity_id is set exactly when resolved and must be one of the pair (R-33, R-34).
  • One live snapshot per academic year and kind: partial unique index one_live_snapshot where superseded_by is null (R-58).
  • Files max 10 MB and stored under their bucket path (file_blobs checks).
